# Android release
The debug build is intended for testing. Native wrappers are generated by the installed Flutter SDK during SETUP. Before a release, confirm the application ID (proposed com.dodo.dodo_smart_school_system), app icon, package label, SDK levels, permissions and privacy policy. Generate a release keystore locally, keep it out of Git, configure key.properties and Gradle signingConfigs.release; ensure release does not use debug signing. Test release APK; check signature and build AAB after signing verified. The provided BUILD_ANDROID script intentionally blocks release until signing is integrated. iOS release needs macOS/Xcode or authorized cloud signing. Neither APK nor AAB is in this source ZIP.
